# NetGuard - NetEase Server Protection

## 简介

NetGuard 是一款专为网易我的世界租赁服务器设计的防锁服保护工具。当你的服务器被恶意攻击锁服时，本工具可以帮助服务器恢复正常运行。

## 功能特点

- ✅ 使用标准 RakNet 协议建立合法连接
- ✅ 发送合法 ACK 确认包，帮助服务器清理数据队列
- ✅ 实时统计防御数据（发送/接收数据包、成功连接数）
- ✅ 多线程并发防御，提高保护效率
- ✅ 断线自动重连，持续保护服务器

## 运行环境

- Python 3.6+
- Windows / Linux / macOS / Android (Termux)

## 使用方法

### 1. 运行脚本

```bash
python unlock.py
```

### 2. 输入配置信息

```
============================================================
  NetGuard - NetEase Server Protection
  Version: v1.0 
============================================================

请输入目标服务器信息：
目标服务器IP: 192.168.1.100
目标服务器端口: 19132
防御线程数（默认39）: 20
```

### 3. 开始防御

脚本启动后会自动开始保护服务器，按 `Ctrl+C` 停止运行。

### 安卓使用方法

#### 方法一：原生Shell脚本（推荐）

不需要安装Python，直接使用安卓系统自带工具（需要root权限或Termux）：

```bash

# 2. 赋予执行权限
chmod +x unlock.sh

# 3. 运行（交互模式）

# 或命令行模式

```

**注意**: 安卓原生Shell版本使用系统自带的 `nc` 和 `xxd` 命令实现网络通信。由于不同安卓设备的系统工具版本差异较大，**这个版本可能没有用**，建议优先使用Python版本。

在Termux中安装Python并运行：

## 工具原理

### 锁服攻击原理

我的世界网易租赁服锁服攻击是通过发送恶意 NACK 包拒绝所有数据序列，让服务器不断重传数据导致卡顿甚至崩溃。

### 防御原理

本工具使用标准 RakNet 协议建立合法连接，发送合法 ACK 确认包，帮助服务器清理数据队列，抢占连接槽位，让攻击者无法获得足够的连接来实施攻击。

### 合法数据包类型

| 类型 | 功能 |
|------|------|
| 0x05 | Ping - 探测服务器 |
| 0x07 | OpenConnectionRequest - 打开连接请求 |
| 0x09 | ConnectionRequest - 连接请求 |
| 0xC0 | ACK - 确认收到数据 |

## 使用建议

1. **建议在服务器正常时就启动本工具**，提前抢占连接槽位
2. **线程数建议设置为服务器最大玩家数**，不要超过服务器承载能力
3. **启动后保持运行**，即使被攻击也能自动防御
4. 如果服务器已经被攻击，启动后等待几分钟，服务器会逐渐恢复

## 统计数据说明

| 统计项 | 说明 |
|--------|------|
| 成功连接 | 成功完成完整 RakNet 握手流程的次数 |
| 防御次数 | 累计防御的攻击次数 |
| 发送 | 发送的数据包总数 |
| 接收 | 接收的数据包总数 |

## 版本历史

### v1.0 (2026-07-27)

**简介**: 正式版本，提供完整的防锁服保护功能。

**核心功能**:
- 使用标准 RakNet 协议建立合法连接（0x05 Ping、0x07 OpenConnectionRequest、0x09 ConnectionRequest）
- 发送合法 ACK 确认包（0xC0），帮助服务器清理数据队列
- 多线程并发防御，默认39个线程同时保护
- 实时统计防御数据（成功连接数、防御次数、发送/接收数据包数、拦截数）
- 断线自动重连机制，持续保护服务器
- 代理模式：正常玩家通过代理端口连接，攻击IP被拦截
- 攻击检测：识别高频握手IP并自动拉黑
- 支持命令行参数和交互输入两种模式
- 支持安卓 Termux 运行

**使用说明**:
- 运行 `python unlock.py`（交互模式）
- 或 `python unlock.py IP 端口 线程数 代理端口`（命令行模式）
- 脚本自动开始保护，按 `Ctrl+C` 停止
